# Python Session 3 Tasks

This repository contains Python implementations demonstrating the use of lists, dictionaries, loops, sets, and basic data manipulation.

- Update values
- Add and remove dictionary entries

### 3. Classroom Management
- Display student GPAs
- Identify high-performing students
- Remove duplicate sign-ups using sets
